# Superreach evals

Evaluations for Superreach's AI workers.

| Folder | What it holds |
|---|---|
| [`functional-evals/`](functional-evals/) | End-to-end tests of business scenarios, one file per vertical use case, generated from the use-case definitions in [adamcarleysr/use-cases](https://github.com/adamcarleysr/use-cases) |

The platform eval suite (behaviour that holds in every use case, such as never inventing data or never showing internal IDs) is defined in the use-cases repository's `reference/guardrails.md`. It isn't drafted here yet.
